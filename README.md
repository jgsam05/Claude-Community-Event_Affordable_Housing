# Claude-Community-Event_Affordable_Housing
UCI × SoCal Affordable Housing. Form a team, pick a lane, and build a working prototype with Claude by 2:30.

## Repo layout

- `parcel-screener-prototype/` front end (map + list, opens with `?api=` to use the backend)
- `backend/` data pipeline, scoring engine and API (see `backend/README.md`)
- `docs/DATASETS.md` every input dataset: source, license, refresh date, how it is used ([CSV](docs/datasets.csv))
