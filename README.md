# Claude-Community-Event_Affordable_Housing
UCI × SoCal Affordable Housing. Form a team, pick a lane, and build a working prototype with Claude by 2:30.

## OCA

OCA is a free screening tool: enter an Orange County, CA ZIP code and get a ranked, mapped list of parcels that are strong candidates for affordable housing development or preservation, using only free public datasets. Each parcel shows development potential, location quality and feasibility risk, with sources and a confidence level for every component.

## Repo map

- `design/DESIGN.md`: the OCA design principles and style guide (name, logo, color, type, layout, voice, scores and video). Start here before changing any screen.
- `design/oca-canvas/`: brand, UI designs (friendly search and data-tool views), score report, how-to-use page and 30-second demo video storyboard. See its README for the file list. All parcels and scores shown are illustrative sample data.
- `docs/data-pipeline-task.md`: data pipeline and API task spec for the back end.
